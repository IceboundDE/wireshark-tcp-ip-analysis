# Wireshark TCP/IP Analysis

## Objective

The objective of this project was to practice basic packet analysis using Wireshark and strengthen my understanding of TCP/IP networking fundamentals.

This project focuses on how devices communicate over a network and how packet-level analysis can support troubleshooting, network visibility, and cybersecurity investigations.

## Tools Used

- Wireshark
- Web browser
- TCP/IP traffic
- HTTP traffic
- HTTPS traffic

## What I Practiced

- Reviewing captured network packets
- Identifying source and destination IP addresses
- Observing TCP communication
- Reviewing ports 80 and 443
- Comparing HTTP and HTTPS traffic
- Understanding basic packet structure
- Connecting network activity to cybersecurity concepts

## Key Concepts

### TCP/IP

TCP/IP is the foundation of how devices communicate across networks. Understanding TCP/IP helps analysts recognize normal network behavior and identify activity that may require further investigation.

### Ports 80 and 443

Port 80 is commonly used for HTTP traffic. Port 443 is commonly used for HTTPS traffic. Reviewing these ports helps build understanding of web traffic and encrypted communication.

### Packet Analysis

Packet analysis allows cybersecurity analysts to inspect network communication at a detailed level. This can help with troubleshooting, investigation, and identifying unusual network behavior.

## Security Relevance

Wireshark is useful for cybersecurity because analysts often need to understand network traffic, identify suspicious communication, verify connections, and support incident response investigations.
